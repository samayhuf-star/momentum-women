# Womentum - Women workout Coach

Guided workouts for iPhone, with a Today view, a timer or a rep counter, and on-screen form cues.

Built with Expo, React Native, and Expo Router.

## Features
- Today, beginner plan, exercise library, and on-device progress (free)
- Additional training plans with Momentum Pro
- StoreKit 2 purchases via expo-iap (no RevenueCat)

## Run
```bash
npm ci
npx expo start
```

## Scripts
- `npm run typecheck`
- `npm run lint` (same as typecheck)

Exercise stills in `assets/exercise-media/` are the files listed in `assets/exercise-media/LICENSE-SOURCES.md`. They are Open Exercise Illustrations (CC0 1.0), plus one Wikimedia Commons photograph, Pilates Hundred by Helisusa (CC BY-SA 4.0). Exercises without a matching still are hidden and are not shown. Do not add files under `assets/gifs/`.
